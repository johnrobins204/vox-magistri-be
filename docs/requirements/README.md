# Requirement Restatement Log

Every requirement, need, or desired outcome handled through the coworking
workflow MUST first be restated using RFC 2119 keywords (MUST, MUST NOT, SHOULD,
SHOULD NOT, MAY, REQUIRED, OPTIONAL) before any architecture or spec work
begins. The restatement is a normative, testable statement — not a paraphrase.

Each restatement is logged below with the next sequential `REQ-NNNN` id, and
linked forward to any ADR and spec it produces.

See [docs/adr/README.md](../adr/README.md) and
[docs/specs/README.md](../specs/README.md) for the rest of the traceability
chain.
